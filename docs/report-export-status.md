# 个人周报长图导出验证

## 已实现

- 将页面现有收据提取为 `ReportReceipt`，屏幕与导出复用同一组件，保留纸面收据、内容顺序及末尾印章。
- 导出使用独立 Flutter render tree，以固定 390 逻辑像素宽、自然完整高度布局，2 倍像素生成 PNG；不依赖报告在 ListView 中是否已经绘制、是否已滚出屏幕。沿用当前主题与文字缩放。
- 页面筛选和导出函数同时要求 `kind == personal`、非空当前用户 ID 与 `report.userId` 精确相等。未知归属、小队周报、其他成员个人周报均拒绝导出。导出组件只接收单份本人报告，不接收小队快照、队友头像、成员列表或评论。
- 在异步调用前设置并检查导出锁，按钮禁用，防止同一帧重复点击。异常展示可重试提示并释放锁；取消不记分享成功，只有系统返回 success 才调用 `share_report`。
- 分享定位使用实际按钮的屏幕范围，支持 iPad 系统分享锚点。每次导出使用独立临时目录，避免重复操作覆盖分享扩展仍在读取的文件；临时文件由系统回收。
- 图片尺寸过长时明确报错并建议使用队内分享，不截断内容。绘制资源在成功或异常后释放。

## 实际验证

命令：`scripts/flutter.sh test test/report_export_test.dart`，2 项通过。

1. 在 375×667 测试视口中，不挂载任何屏幕内收据，实际离屏导出含 18 段亮点、3 个计划和末尾建议的个人周报。使用 PNG 解码器验证 **780×4734** 像素（390×2367 逻辑像素，约 3.5 个视口高度），并扫描最底部朱红印章的上下边框和底部留白，确认末尾未裁切；本人 ID 为空、未知归属、队友与小队报告拒绝导出。
2. 真实 ReportsPage widget：同一按钮回调连续触发两次仅调用一次分享；分享失败后提示并恢复按钮；再次取消不记成功，随后成功只记一次；“我的周报”不展示队友与未知归属数据，“小队周报”没有图片导出入口。

合成样本：`output/qa/report-export.png`。已实际查看图片，中文、图标、末尾建议与完整印章清晰。QA 字体使用本机 STHeiti，图标加载应用 Cupertino 字体；不更改生产字体，也不把样本当作真实用户数据。

检查命令：`scripts/flutter.sh analyze lib/features/reports test/report_export_test.dart`，No issues found。

## 验证边界与回滚

变更仅涉及 reports 页面、两个提取文件和独立测试；可将 reports 页面恢复为修改前版本并删除新增导出/收据文件与测试，不涉及数据库迁移或用户数据变更。
