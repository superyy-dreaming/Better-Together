# AI 接口与性能验证约束

维护识别上下文、结果保存接口或性能基准时读取。

- PostgreSQL 函数可能返回单个 JSON 数组，也可能返回行集。调用方必须核对返回类型；已经是 JSON 数组的结果不能再 jsonb_agg。候选计划接口的数据库测试必须断言元素是对象并包含 id/category，客户端也必须拒绝错误结构，不能把错误结构静默当成“没有候选计划”。
- 识别 ready 不代表自动归类正确。真实性能复测同时检查候选数量、计划匹配、完整日期、数值单位和摘要；全为 ALL 不能仅凭结构 ready 判定通过。失败轮次保留并标注，修复后另开一轮，不覆盖原始数据。
- 耗时使用实际墙钟，记录 App lifecycle。计时器在系统暂停期间不能保证按墙钟准时回调；超过超时预算的观测不能直接解释为模型耗时。无证据时标注未知，不通过调大 timeout 掩盖。
- BYOK Key 只能从设置进入设备安全存储。测试可记录模型／端点元数据指纹、候选数量、阶段和状态，不读取、复制或打印 Key。旧后端代理和持钥架构不得作为回滚版本。
- 已部署迁移不改写。修复用追加迁移，并先在临时数据库运行完整接口形状及业务回归，再核对 remote dry-run。
