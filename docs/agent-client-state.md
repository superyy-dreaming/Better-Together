# 客户端会话与快照边界

分页列表后台重验第一页时，必须保留后续已加载页及其游标语义。只在用户主动重载或权限明确失效时重置分页；不能一边清掉中间页、一边继续使用旧末页游标。验收覆盖后台刷新保留第二页与主动刷新重置两个场景。

涉及登录、换账号、离队、成员权限或异步快照时读取本文件。

- Riverpod 3 的 AsyncNotifier 在设置 AsyncLoading/AsyncError 时会自动带上 previous value。身份切换不能靠赋一个 loading/error 清除私密快照。当前 AppController 使用 `Notifier<AsyncValue<AppSnapshot>>` 显式管理，禁止无回归测试地改回自动保留行为。
- 网络不可用可保留同一账号快照；身份失效、权限拒绝、已成功离队不可继续显示旧权限快照。每次异步读取检查 session ID 与读序号，防止旧请求覆盖新会话。
- Realtime 事件仅为受影响范围重新读取的信号，数据展示以授权摘要、分页或详情响应为准。不要把未完整验证的事件 payload 直接合并成可见历史。每范围只保留一个进行中的请求；其间再次失效则标记 dirty，完成后再读取一次，不能丢掉变化或并发覆盖。
- 首屏摘要不得等待图片签名和正文下载。分页集合需独立维护成员 ID 与 cursor；不要用已下载详情的数量推断今日完成或历史日历汇总。
- 写操作提交成功与后续读取成功是两个状态。先合并服务端确认的记录或资料，再后台核对；刷新异常进入同步提示，不能让已保存操作显示保存失败。资料局部响应必须保留完整接口的 wire 类型和小队有效时区。
- 私有媒体授权与缓存文件分开管理。文件键绑定账号、媒体引用、内容版本和规格，不绑定短期签名 URL；签名过期只更新授权，已有有效文件不重复下载。冷启动必须先验证权限再展示队友缓存，不能用文件存在替代授权。
- 换账号、离队或可见性 epoch 变化要撤销访问凭据、丢弃越权快照、清除磁盘及 Flutter 已解码图像，并通知已渲染图片。旧下载回调必须检查 session/epoch，不能在清理后重新显示旧权限图片。普通同账号网络异常保留记录，单图错误在原位重试，不全页阻塞。
- 验收至少包含退出后延迟响应、直接切换账号、离队成功但下一次读取失败、同账号网络中断仍保留记录四个场景，见 `app/test/controller_test.dart`。
- 缓存改动另验签名续期不重下正文、并发同图合并、权限撤销后拒绝本机文件、切账号清理且刷新已渲染图片，见 `app/test/media_cache_test.dart`。

## 有状态表单与密钥

- 表单字段不能直接散放在会卸载屏外子项的 ListView 中。`Form.validate()` 只检查仍挂载的字段；较长的设置表单使用滚动容器中的完整 Column，或在模型层独立校验所有输入。验收应从最底部提交时仍拒绝顶部的无效输入。
- 供应商密钥只由密码输入控制器短暂持有，不进入 AppSnapshot、SharedPreferences、日志和错误原文；服务只返回 has_key 元数据。离页和切换账号清空输入，旧账号异步结果不得恢复页面。
