# Better Together · 团团陪你

参考多邻国交互语言的原创卡通 UI 原型，供视觉审核。所有数据和识别均为示例，现有 App 未修改。

直接打开 index.html 可看六页原型，也可运行：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

http://127.0.0.1:4174 为审核画板。?screen=today / capture / success / team / report / plans 为单页互动预览。首页点击打卡，修改纪要并盖章，再进入小队；顶部齿轮可试深色和 AI 设置。刷新恢复示例数据。

preview.png 为六页总览；images/ 内为高清单页图。设计依据和边界见 DESIGN.md。没有真实 AI、相机、存储或账号调用，请勿填写真实密钥。
