# Better Together「同频」UI 原型

独立的可点击设计提案。现有 Flutter App、后端、数据库和根设计系统均未替换。

## 打开
直接打开 `index.html` 即可离线体验，也可以在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。无需安装依赖，字体、图片、图标和 QR 脚本已随目录提供。package.json 只记录资源来源版本。

## 推荐审核顺序
1. 今日：查看下一步、完成记录和同伴入口。
2. 点击底部＋：选择示例照片，逐图改标签、编辑纪要，再盖章。
3. 小队：新打卡会出现；点赞、回应、质疑和逾期戳一下分别体验。
4. 邀请：8 位码、二维码、模拟扫描、队名和固定时区确认。
5. 周报：个人与小队切换、发送到演示动态、下载个人长图。
6. 设置：自定义 AI、通知偏好、隐私说明与深色模式。

右侧可选择 AI 暂不可用 / 非当天照片场景。手机在打卡页面底部切换。刷新或大屏右上重置按钮恢复初始示例。

## 说明
所有人物、进度与识别内容均为演示。原型不会真实识别照片或调用服务，不要输入真实 API 密钥。选择的本机图片仅在当前页面预览，不上传。扫码页面明确模拟流程，不访问相机。原型二维码仅为本机预览 URL，不能用于正式 App。

源代码：index.html、style.css、app.js。设计决策：DIRECTION.md。设计系统：DESIGN.md。验证与限制：VALIDATION.md。

回滚：关闭预览或移除本目录即可，不涉及现有 App。
