# Better Together · 同频

这是独立 Web 审核原型的设计系统，不覆盖现有 App 设计系统。

## 视觉语法
Operate，重新建立视觉。共享日常为叙事中心：日期、照片、记录、成员进度、周报节奏。避免收据、纸纹、邮票边框和旧印章造型。产品仍使用“已盖章”表示完成。

## Token
浅色：背景 #F7F8FA，表面 #FFFFFF，正文 #191B20，辅助 #626872，边界 #D9DDE4，主色 #2854DC。主色只服务当前导航、主行动、关键文字、完成轨道。
深色：背景 #181C22，表面 #22272F，正文 #F0F2F5，辅助 #B0B8C6，边界 #3C4553，主色 #9CB5FF，主色上文字 #11254E。
Manrope 自托管，中文 PingFang SC / Microsoft YaHei。正文及说明采用 rem，允许浏览器字体偏好缩放。标题 34–36px，重要内容 15–25px，辅助 11–13px，原型状态说明 9–10px。采用 4/8px 间距，手机横边距 22px，图片 22px 圆角，按钮 16px，列表不额外包卡。

## 布局与交互
四个页面导航：今日、小队、周报、计划；中心“＋”为单独打卡操作，以实心方形与导航项区分。自包含的识别、确认、成功任务隐藏下方导航，有明确返回。
当前行为以浏览器原型演示，不声称采用 iOS 官方 Web UI 组件。未来原生实现需使用平台语义、系统手势及可访问性。
照片主导今日与小队内容；周报格条对应真实示例次数；设置用分组列表；编辑任务采用原生 dialog 并保留键盘退出与焦点约束。成功只有短促 scale/opacity 动效，减少动态效果时停用。

## 断点
<768：全窗口 App 原型。768–1190：评审导航＋限宽手机预览。>=1191：增加设计解释与场景选择。原型预览维持手机内容宽度，外围画布不代表未来平板 App 的正式布局。

## 资产与来源
assets/SOURCES.json 记录图片与字体 URL。Unsplash 三张照片仅用于示例内容；无真实用户头像或照片。Manrope OFL，Phosphor 图标 MIT，QR Code Generator MIT（授权说明在原始脚本头部）。图标是库内资源，未手绘 SVG。

## 交付边界
原型模拟 AI、扫码、加入小队、账号及通知，实际可执行本地照片预览、计时、标签和纪要编辑、示例计划编辑、主题切换和个人周报 PNG 导出。刷新可重置所有演示状态，不存储密钥，不向真实服务发送请求。
