当前屏说明

今日 · 先给人一个「还差一点」的理由

首页不堆功能，只回答三件事：我连续了几天、今天还差什么、队友到哪了。连续记录用大数字做锚，小队进度条制造温和压力。

  • 状态：已完成盖章 / 待打卡 / 冻结保护，三态一眼可分
  • 交互：主卡的「去打卡」直达相机，并带入对应计划
  • 文案：断签叙事是「接上」，不是清零羞辱

打卡状态机 · v2

ALL 上传 → AI 识别分类 → 查拍摄日期 → 盖章成功 → 赞 / 评论 → 质疑过半 → 重新打卡

没有「存疑」中间态：验真过就盖章，公道交给队友的质疑票 — 5 人小队满 3 票才打回，既防误杀，也防一个人说了算。

截止 +30 分钟 未完成 → 自动同步小队动态并开放「戳一下」；23:30 后截止的统一 23:30 同步。

给开发的拆分提示

每类计划是一张配置卡：部位无关，字段是「品类 / 频率 / 证明方式 / 纪要字段 / 数据来源」。前端照配置渲染，不为每个品类写死页面。单次打卡目标 60 秒走完。

原型说明：本页为高保真交互原型，数据均为演示数据。AI 验真、纪要与周报在原型中为流程模拟；正式版口径以流程说明文档为准 — 饮食热量标注估算、运动数据来自计时与健康数据、App 不经手任何押金或奖金。
